# Aaron Zhang Blog

Draft personal blog for documenting progress in quant finance and AI agents.

This is a static GitHub Pages-ready site. Open `index.html` locally, or push the
repository to GitHub and enable GitHub Pages from the `main` branch.

## Structure

```text
index.html
styles.css
assets/images/quant-ai-desk.png
posts/
  2026-06-07-starting-the-quant-journey/
  2026-06-07-ai-agents-for-learning/
```

## Add A New Post

Copy one of the folders under `posts/`, rename it with a date and title, then update
the title, date, and article text. Add a link to the new post in `index.html`.
